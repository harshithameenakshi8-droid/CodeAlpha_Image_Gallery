# CodeAlpha Image Gallery

A modern and responsive image gallery developed using HTML, CSS and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features

- Responsive image gallery with 12 images.
- Category-based image filtering.
- Search images by title.
- Add and remove favourite images.
- Save favourites using Local Storage.
- Image lightbox preview.
- Previous and next image navigation.
- Image download functionality.
- Keyboard navigation support.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
CodeAlpha_Image_Gallery/
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
